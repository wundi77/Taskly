Taskly – kurz erklärt

Die Kanban-App für deine Menüleiste

Taskly ist eine kleine Kanban-App (im Stil von Trello), die als Menüleisten-App im Hintergrund läuft. Du organisierst Aufgaben in Boards → Listen → Karten und kannst Karten frei zwischen Listen hin- und herziehen. Alle Daten bleiben ausschließlich lokal auf deinem Mac gespeichert.
1App öffnen & schließen

Taskly läuft dauerhaft als Icon oben in der Menüleiste – kein Fenster im Dock.

  • Klick auf das Icon: Fenster erscheint / verschwindet wieder.
  • Rechtsklick auf das Icon öffnet ein Menü:
  • – „Beim Start automatisch laden“ (Häkchen an/aus)
  • – „Beenden“, um Taskly komplett zu schließen
2Boards

Ein Board ist ein eigenständiges Projekt/Thema, angezeigt als Reiter oben im Header.

  • + Neues Board oben rechts anlegen – Name direkt eintippen, mit Return bestätigen.
  • Rechtsklick auf einen Board-Reiter: umbenennen oder löschen.
  • Klick auf einen Reiter wechselt das aktive Board.
3Listen (Spalten)

Jedes Board hat beliebig viele Listen nebeneinander, z. B. „Offen“, „In Arbeit“, „Fertig“.

  • + Weitere Liste am Ende der Spalten legt eine neue Liste an.
  • „⋯“-Menü im Listenkopf: Liste umbenennen oder löschen.
  • Die Zahl neben dem Titel zeigt die Kartenanzahl.
4Karten anlegen & bearbeiten

„+ weitere Karte“ am Ende einer Liste legt eine neue Karte an. Klick auf eine Karte öffnet die Details.

  • Titel, Beschreibung frei editierbar
  • Farbige Labels zur Kategorisierung
  • Fälligkeitsdatum (überfällige Karten werden rot markiert)
  • Checkliste mit Fortschrittsbalken auf der Karte
  • „Erledigt“-Status & „Karte löschen“
5Karten verschieben

Karten lassen sich frei per Maus ziehen:

  • Innerhalb einer Liste: Reihenfolge von oben nach unten ändern.
  • Zwischen Listen: Karte in eine andere Liste ziehen – auch in eine komplett leere Liste.
6Suche & Darstellung

Im Header findest du zusätzlich:

  • 🔍 Suchfeld – filtert Karten im aktiven Board nach Titel.
  • „Dunkel“ / „Hell“-Umschalter für das Erscheinungsbild.
iGut zu wissen

Alle Boards, Listen und Karten werden ausschließlich lokal auf deinem Mac gespeichert (kein Cloud-Sync). Änderungen werden automatisch beim nächsten Klick auf „Fertig“ bzw. direkt bei Aktionen wie Verschieben oder Löschen gesichert.
